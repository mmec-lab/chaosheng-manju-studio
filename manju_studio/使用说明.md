# 潮生 · 漫剧工作台

打开 http://127.0.0.1:8765 ，或双击上一级目录的「启动漫剧工作台.command」。首次启动后可以关闭启动窗口；后台程序会继续运行。Mac关机后需要重新启动工作台。

## 推荐操作顺序

1. **设置与帮助 → 检查连接**。视频走 Tailscale + ComfyUI，配音走 SSH 公钥登录。Base 为参考声音克隆模型，CustomVoice 为预设音色模型。
2. **剧本与分集**。写清系列设定、上一集后果、本集目标和结尾悬念。支持手写或配置兼容文本服务后 AI 续写与拆镜头。配置云端服务可能产生该服务的费用。
3. **角色与音色**。上传角色定妆图并锁定。上传有权使用的参考录音，填写完全对应的原文，保存后生成一条试听；确认后锁定音色。不要把不同角色设为同一说话人。更换音色会使该角色旧配音失效。
4. **分镜工作台**。一个镜头描述一个主要动作。指定出镜角色、准确对白、说话角色。首镜头建议上传场景图；后续默认使用上一镜头末帧。JSON 导入会追加，不覆盖旧镜头。
5. **生成画面与配音**。先用一个镜头验证，再批量。当前已安装视频工作流固定480×864、24fps、124帧（约5.17秒），不承诺任意时长。任务串行执行，避免工作台内部同时占用4090。服务器其他任务不会被强行终止。
6. **逐镜试听审核**。确认人脸、服装、场景、对白、音色及口型，再标记通过。画面预览播放源视频；独立配音在旁边试听，最终合成时才替换。
7. **成片与导出**。添加音乐，调节音量，导出。删除原有混合音轨，使用独立对白与音乐，对白出现时自动压低音乐。输出 MP4 与单独 SRT；SRT 按镜头排时，非字级对齐。

## 防止重蹈覆辙

- 修改台词或说话角色后，原配音自动失效，需重做。
- 定妆和音色分别锁定；锁定只防止配置误改，不是模型一致性的保证。
- 未通过审核的镜头不能导出；对白过长会报错，不会截断。
- 新导出和重做画面保存为新文件，旧版本仍保留。
- 暂停只阻止后续任务。取消已提交的远端任务不会中断其他人的计算。
- 导出的原始环境声会被删除；此版未加入独立音效轨。
- 调长镜头合成时长会在尾部定格，请优先生成衔接镜头。

## 当前边界

- 已实现：项目、分集、剧本、角色定妆上传、声音配置与试听、分镜编辑和排序、导入导出、H3视频调用、Qwen配音/克隆、任务队列、失败重试、视频任务恢复查询、审核、混音、成片及字幕导出。
- 编剧接口：兼容 chat/completions，需用户配置可用文本模型后验证；不内置账号或付费额度。
- 尚未实现：自动生成角色定妆图、自动口型重定向、自动人脸一致性验收、音效素材库、字幕烧录、云端视频付费接口、多用户权限系统。
- 这版是可运行的本地生产工作台，不是完全自动、无需审核即可发布的流水线。

## 文件与恢复

- 项目数据：`manju_studio/data/state.json`，原子写入保存。
- 上传素材：`manju_studio/uploads/`。
- 生成素材：`manju_studio/renders/`。
- 日志：`manju_studio/data/server.log`。
- 旧剧集：原来的 `raft_series/`，启动时导入一次，不自动覆盖用户修改。
- 备份：侧栏下载 JSON 数据备份；迁移时请同时复制整个工作区，JSON不包含媒体文件。
- 文本服务密钥：单独保存在本机 `data/text_service.key`，不返回浏览器、不包含在JSON备份中。
- SSH专用密钥：`~/.ssh/id_ed25519_manju_studio`；服务器只保存公钥，不在网页存储服务器密码。
